# 🔍 Análise de Sentimentos — Brasil Participativo

Bem-vindo ao blog oficial do projeto **Analisador de Sentimentos**, desenvolvido por estudantes de Engenharia de Software da UnB – Campus Gama, como parte da disciplina **Métodos de Desenvolvimento de Software**.

---

## 🎯 Objetivo do Projeto

A proposta deste projeto é **coletar, classificar e visualizar** os sentimentos expressos nos comentários da plataforma **Brasil Participativo**, com o intuito de:

- Apoiar decisões de políticas públicas
- Compreender a opinião da sociedade civil
- Oferecer dados de fácil leitura para cidadãos, pesquisadores e gestores públicos

---

## ⚙️ Funcionalidades

- 📥 Coleta automática de comentários via API GraphQL
- 🤖 Classificação de sentimentos (positivo, neutro e negativo) com modelo de IA
- 📊 Dashboard visual com gráficos e filtros interativos
- 🔎 Busca por termos e filtros por tema, sentimento e período
