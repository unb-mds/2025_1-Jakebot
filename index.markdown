<section>
  <h2>🌟 Objetivo do Projeto</h2>
  <p>
    Este projeto tem como finalidade aplicar técnicas de <strong>Aprendizado de Máquina</strong> e <strong>Processamento de Linguagem Natural</strong> para analisar os sentimentos dos comentários feitos por cidadãos na plataforma Brasil Participativo.
  </p>

  <h2>🚀 Como Funciona</h2>
  <ul>
    <li>Coleta automática de comentários via API GraphQL</li>
    <li>Classificação em sentimentos: <strong>Positivo</strong>, <strong>Neutro</strong> e <strong>Negativo</strong></li>
    <li>Visualização dos dados em um painel com filtros e gráficos</li>
    <li>Busca por palavras-chave, tema e período</li>
  </ul>

  <h2>📊 Resultados Esperados</h2>
  <p>
    Esperamos contribuir para uma análise mais acessível da opinião popular, auxiliando gestores, pesquisadores e cidadãos a entender melhor as demandas da sociedade.
  </p>
